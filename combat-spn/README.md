# Combat СпН: сайт-концепт

Односторінковий сайт-магазин для бренду військового одягу й спорядження **Combat СпН** (камуфляж «Хижак»). Працює без сервера: відкрийте `index.html`.

Дані (49 товарів, ціни, описи, фото, контакти, історія) зібрано з офіційного сайту spn.kiev.ua 16.11.2026.

## Що є на сайті
- **«Приціл дрона» на першому екрані.** Лінза з нічним баченням, координатами й статусом «ціль не визначено» йде за курсором. На телефоні вона патрулює сама.
- **Каталог.** Пошук, 12 категорій, фільтр за ціною, сортування, «Показати ще». Під курсором показується друге фото товару.
- **Картка товару.** Галерея (свайп, стрілки), опис, вибір розміру й зросту для одягу, кількість, посилання на товар (`#p-…`).
- **Кошик.** Зберігається в браузері. Оформлення: ім'я, телефон, місто, відділення Нової пошти. Замовлення з номером складається в повідомлення й надсилається у WhatsApp (з готовим текстом), Viber, Telegram або на пошту. Текст також копіюється.
- **Калькулятор розміру.** Розмір = обхват грудей / 2, зріст 1–6. Обраний розмір підставляється в картку товару.
- **Форма для підрозділів (опт).** Можна підставити товари з кошика.
- **Блок «Хижак».** Патент, хронологія 2005–2024, піксельний камуфляж, що «складається» під час прокрутки (стилізація, не оригінальний візерунок).
- **Переваги, «Про нас» із сертифікатами** (відкриваються великими), **контакти** зі статусом «працюємо / зачинено» за київським часом.
- **Дві мови** (UA / EN), нижня панель на телефоні, плавний скрол і анімації (GSAP, ScrollTrigger, Lenis).

## Що оновлювати
| Що | Де |
|---|---|
| Товари, ціни, описи, фото | `js/products.js` (фото в `img/p/`) |
| Телефон, email, графік | `js/app.js`: `PHONE`, `EMAIL`, `HOURS`; плюс блок контактів в `index.html` |
| Тексти та переклад | `index.html` (UA) і `js/i18n.js` (EN) |
| Смужка «неофіційний концепт» | рядок `<p class="concept">` в `index.html` |

У режимі EN описи товарів лишаються українською (є примітка), а назви моделей — власні назви бренду.

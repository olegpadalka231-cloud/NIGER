# Сайт BB Pets Groom

Готовий односторінковий сайт для грумінг-салону. Працює без сервера: відкрийте `index.html` у браузері.

## Що є на сайті
- Прайс-калькулятор: ціни перераховуються під розмір собаки, послуги додаються в «Ваш візит» із сумою й тривалістю.
- Галерея «Наші пси» з фільтром і переглядом у великому розмірі.
- Онлайн-запис у 4 кроки: пес, послуги, дата й час, контакти. Незавершена заявка зберігається, якщо закрити вкладку.
- Блоки «Про студію», «Процес», FAQ, контакти, Instagram.
- Світла й темна теми, адаптація під телефон.

## Анімації (js/motion.js)
Зроблені на GSAP + ScrollTrigger і Lenis (плавний скрол), бібліотеки підключаються з CDN.
- Прелоадер із логотипом, після нього заголовок hero виїжджає рядками, а фото відкривається «шторкою».
- Паралакс фото, текст «Про студію» проявляється слово за словом у такт скролу.
- Біжучий рядок порід прискорюється й розвертається разом зі скролом.
- Блок «Процес» на комп'ютері закріплюється й гортається горизонтально.
- Фото галереї відкриваються шторкою, курсор «Дивитись», магнітні кнопки, ціни «перелічуються» при зміні розміру.
- Якщо в системі вимкнені анімації (prefers-reduced-motion) або CDN недоступний, сайт працює статично.

## Що замінити перед запуском (зараз це заглушки)
| Що | Де |
|---|---|
| Ціни, тривалість, назви послуг | `js/data.js` → `SERVICES` |
| Фото собак у галереї | покладіть фото в `img/` і вкажіть у `js/data.js` → `GALLERY` → `photo` |
| Фото hero, «Про студію», запису | `img/hero.jpg`, `img/brushing.jpg`, `img/studio.jpg` (замініть файли, зберігши назви) |
| Адреса, телефон, графік | `index.html`, секція `id="contacts"` |
| Вільні години для запису | `js/app.js` → `slotsFor()` (зараз зайнятість умовна) |

Фото-заглушки взяті з Unsplash (ліцензія Unsplash дозволяє безкоштовне комерційне використання). Краще замінити їх на справжні фото ваших клієнтів з Instagram.

## Як отримувати заявки
Зараз заявка показує клієнту підтвердження, але **нікуди не надсилається**. Підключіть один із варіантів, додавши функцію в `index.html` перед `js/app.js`:

```html
<script>
window.sendBooking = function (b) {
  // Варіант 1: Formspree (formspree.io, безкоштовно) — заявки приходять на пошту
  fetch('https://formspree.io/f/ВАШ_ID', {
    method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(b)
  });
};
</script>
```

Варіант 2: Telegram-бот. Щоб не світити токен бота у коді сайту, надсилайте заявку через невеликий серверний посередник, наприклад Cloudflare Worker або Make.com.

## Як опублікувати безкоштовно
- **Netlify Drop**: зайдіть на app.netlify.com/drop і перетягніть туди папку `bbpets-site`.
- **GitHub Pages** або **Cloudflare Pages**: завантажте папку в репозиторій.
- Власний домен (наприклад, bbpets.com.ua) підключається в налаштуваннях хостингу.

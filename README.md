# Сайт BB Pets Groom

Готовий односторінковий сайт для грумінг-салону. Працює без сервера: відкрийте `index.html` у браузері.

## Що є на сайті
- **Пухнастий логотип** (`js/fur.js`): напис BB Pets вкритий шерстю на canvas. Курсор або палець розчісує її, а прокрутка підстригає: обрізки падають, і проступають золоті літери.
- **Шкала «сьогодні»** з крапкою «зараз» і статусом «відчинено / зачинено» за графіком.
- **Прайс-калькулятор**, що наїжджає «аркушем» на перший екран: ціни за розміром собаки, панель «Ваш візит» із сумою й тривалістю.
- **«Як проходить візит»**: під час прокрутки підсвічується активний крок, а картка зі світлиною й порадою майстра змінюється.
- **Галерея** з фільтром і лайтбоксом (свайп на телефоні), **хайлайти Instagram**.
- **Конструктор заявки**: людина відмічає пункти, а справа в «бульбашці» Direct живо складається повідомлення. Кнопки: «Скопіювати й відкрити Direct», «Лише скопіювати», «У календар» (.ics), «Очистити».
- **Маршрут**: схема, де пунктир малюється під час прокрутки, кнопка Google Maps, графік на тиждень.
- На телефоні нижня панель «Записатися / Direct / Маршрут». Є дві мови й світла та темна теми.

## Анімації (js/motion.js)
GSAP + ScrollTrigger + Lenis (плавний скрол). Якщо в системі вимкнені анімації або CDN недоступний, сайт працює статично, а стрижка логотипа просто йде за прокруткою.

## Смужка-примітка вгорі
Вона повідомляє, що ціни, адреса й графік орієнтовні. Коли дані підтверджені, видаліть рядок `<p class="concept" …>` з `index.html` і встановіть `--bar-h: 0px` у `css/style.css`.

## Мови
Сайт двомовний: українська (за замовчуванням) і англійська, перемикач UA / EN у шапці. Посилання `…/#en` одразу відкриває англійську.
Українські тексти лежать у `index.html`, англійські у `js/i18n.js` (об'єкт `EN`, ключі збігаються з `data-i18n`). Назви послуг, порід і галереї перекладаються в `js/data.js` (поля `*_en`).

## Запис
Повідомлення складається просто під час заповнення. «Скопіювати й відкрити Direct» копіює текст і відкриває чат @bbpetsgroom. «У календар» завантажує .ics з нагадуванням за 2 години.

## Що замінити перед запуском (зараз це заглушки)
| Що | Де |
|---|---|
| Ціни, тривалість, назви послуг | `js/data.js` → `SERVICES` |
| Фото собак у галереї | покладіть фото в `img/` і вкажіть у `js/data.js` → `GALLERY` → `photo` |
| Фото hero, «Про студію», запису | `img/hero.jpg`, `img/brushing.jpg`, `img/studio.jpg` (замініть файли, зберігши назви) |
| Адреса, телефон, графік (зараз приблизні: Рівне, вул. Студентська) | `js/data.js` → `SALON` |
| Вільні години для запису | будуються з графіка; зайнятість умовна, `js/app.js` → `slotsFor()` |

Фото-заглушки взяті з Unsplash (ліцензія Unsplash дозволяє безкоштовне комерційне використання). Краще замінити їх на справжні фото ваших клієнтів з Instagram.

## Як отримувати заявки
Зараз заявка показує клієнту підтвердження, але **нікуди не надсилається**. Підключіть один із варіантів, додавши функцію в `index.html` перед `js/app.js`:

```html
<script>
window.sendBooking = function (b) {
  // Варіант 1: Formspree (formspree.io, безкоштовно) — заявки приходять на пошту
  fetch('https://formspree.io/f/ВАШ_ID', {
    method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(b)
  });
};
</script>
```

Варіант 2: Telegram-бот. Щоб не світити токен бота у коді сайту, надсилайте заявку через невеликий серверний посередник, наприклад Cloudflare Worker або Make.com.

## Як опублікувати безкоштовно
- **Netlify Drop**: зайдіть на app.netlify.com/drop і перетягніть туди папку `bbpets-site`.
- **GitHub Pages** або **Cloudflare Pages**: завантажте папку в репозиторій.
- Власний домен (наприклад, bbpets.com.ua) підключається в налаштуваннях хостингу.
